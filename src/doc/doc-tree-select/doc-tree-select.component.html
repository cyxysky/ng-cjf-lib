🌲 TreeSelect 树选择

树型选择控件，可以对树形结构数据进行单选或多选操作。支持搜索、虚拟滚动、自定义节点等高级功能，适用于组织架构、文件夹、分类目录等场景。

何时使用

  • 需要从有层级关系的大量数据中进行选择
  • 组织架构、部门人员选择
  • 文件夹目录、分类目录选择
  • 支持搜索的多级数据筛选
