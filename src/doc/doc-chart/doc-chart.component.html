Chart 图表

功能丰富的数据可视化组件，支持柱状图、折线图和饼图

使用指南

  • ✨ 支持柱状图、折线图、饼图三种图表类型
  • 🎨 丰富的自定义配置选项
  • 📱 完全响应式设计
  • 🖱️ 支持点击和悬停交互
  • 🔧 自定义悬浮框模板
  • 🎬 可配置的动画效果

刷新数据

最基本的柱状图用法，展示一组数据的比较。

只需提供 data 数组，每个数据项包含 name 和 value。

多系列柱状图可展示多组数据的对比，每个类别包含多个数据系列。

点击图例可以切换显示/隐藏对应的数据系列。

折线图用于展示数据的趋势变化，适合时间序列数据。

将 chartType 设置为 'line' 即可创建折线图。

通过 line.areaFill: true 启用折线下方的区域填充。

可使用 line.areaFillColor 自定义填充样式。

饼图用于展示不同类别数据的占比关系。

通过配置 showLabels 和 showPercentage 显示名称和百分比。

通过设置 innerRadius 可以创建环形图。

环形图比传统饼图更现代化，适合在中心显示总计数据。

通过 options 中的 colors 数组自定义图表颜色。

自定义颜色可以增强数据的视觉区分度或符合品牌标识。

通过设置 hoverEffect 启用悬停效果和悬浮框。

将鼠标悬停在图表元素上，可以看到详细数据信息。

通过设置 onClick 回调函数响应图表元素的点击事件。

回调函数接收包含完整上下文信息的对象，便于进行后续处理。
