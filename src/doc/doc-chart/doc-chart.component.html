📊 Chart 图表

功能丰富的数据可视化组件，支持柱状图、折线图和饼图。提供丰富的自定义配置选项，完全响应式设计，支持点击和悬停交互。

何时使用

  • 需要直观展示数据趋势和对比关系
  • 制作数据报表和分析看板
  • 实时监控系统状态和指标
  • 用户交互式数据探索场景
