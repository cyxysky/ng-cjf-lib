💬 Tooltip 文字提示

简洁优雅的文字提示气泡框，为用户提供恰到好处的额外信息。支持多种触发方式和位置，让界面交互更加友好和直观。

何时使用

  • 需要进一步说明的界面元素
  • 鼠标悬停或点击时显示提示
  • 简短的帮助信息展示
  • 不占用额外界面空间的说明
