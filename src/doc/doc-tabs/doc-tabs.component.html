📑 Tabs 标签页

选项卡切换组件，用于在不同视图之间进行切换展示。支持多种样式、位置设置、懒加载等高级功能，是内容分类展示的理想选择。

何时使用

  • 内容较多需要分类展现
  • 不同类型的内容需要平级切换
  • 多个功能模块的界面组织
  • 提升页面空间利用率
