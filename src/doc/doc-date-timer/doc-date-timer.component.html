📅 DateTimer 日期时间选择器

用于选择日期、时间或日期时间的输入组件。当用户需要输入一个日期，可以点击标准输入框，弹出日期面板进行选择。支持多种精度和格式的时间选择。

何时使用

  • 当用户需要输入一个日期，可以点击标准输入框
  • 弹出日期面板进行选择，避免手动输入错误
  • 支持年、月、日、时间等多种精度选择
  • 需要范围选择时，如开始和结束日期

日期时间选择器支持单选和范围选择两种类型：

单选
single 选择单个日期或时间，适用于生日、截止日期等场景
范围
range 选择开始和结束时间范围，适用于统计周期、活动时间等

日期时间选择器有三种尺寸，适应不同使用场景：

S
小尺寸 (small) 适用于紧凑的布局空间，如表格内嵌编辑
M
默认尺寸 标准大小，适用于表单和大多数业务场景
L
大尺寸 (large) 更易点击，适合移动设备和重要操作

日期时间选择器支持选择一个时间范围，提供完整的区间选择体验：

可以通过设置 disabledDate 和 disabledTime 来禁用特定的日期和时间：

函数式禁用规则，支持复杂逻辑
可禁用周末、节假日等特殊日期
支持禁用特定时间段，如非工作时间
提示：禁用规则通过回调函数实现，可以根据业务需求自定义复杂的禁用逻辑。

可以为日期选择器添加状态（error、warning）以及设置无边框样式：

正常状态 默认样式，无特殊状态指示
错误状态 (error) 表示输入有误或验证失败，通常配合表单验证使用
警告状态 (warning) 提示用户注意或可能的问题，如即将到期
无边框样式 去除边框，适合特殊布局需求或融入背景
