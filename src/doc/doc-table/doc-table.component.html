📊 Table 表格

功能强大的表格组件，用于展示大量结构化数据。支持排序、筛选、分页、虚拟滚动、树形展示等高级功能，是企业级应用的数据展示利器。

何时使用

  • 展示大量结构化数据
  • 需要对数据进行排序和筛选
  • 后台管理系统的数据列表
  • 复杂的数据分析和报表展示
