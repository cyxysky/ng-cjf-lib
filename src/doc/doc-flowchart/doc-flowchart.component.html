📊 MultiDimensionalFlowchart 多维流程图

用于展示具有多个维度的流程图，支持主流程和子流程的可视化展示。适用于复杂的业务流程、工作流程等需要体现层级关系和多维度信息的场景。

何时使用

  • 展示复杂的流程关系和层级结构
  • 项目开发流程的可视化展示
  • 业务流程图的多维度展现
  • 工作流程中的分支和阶段管理

代码演示

最基本的流程图展示，通过配置以下属性实现：

steps - 定义流程步骤和节点信息
stages - 定义流程阶段
nowStage - 指定当前所处阶段

组件支持更复杂的配置和自定义：

stageArray - 自定义阶段布局的多维数组
state - 流程状态：active（活跃）、hold（暂停）、close（关闭）
stateText - 非活跃状态时显示的文本
