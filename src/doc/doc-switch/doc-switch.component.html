🔘 Switch 开关

开关组件用于在两种状态间切换，提供清晰的开启/关闭状态反馈。常用于设置开关、功能切换等场景。

何时使用

  • 需要切换两种对立状态时
  • 在设置页面开启/关闭功能
  • 控制某个功能的启用状态
  • 需要即时生效的状态切换

代码演示

最简单的开关用法，点击可在开启和关闭状态间切换。

禁用关闭状态

禁用状态下的开关不响应用户点击事件。

通过 switchDisabled 属性控制禁用状态。

加载中状态用于异步操作时防止用户重复点击。

通过 switchLoading 属性显示加载状态。
