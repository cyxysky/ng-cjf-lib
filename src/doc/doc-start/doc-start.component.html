一套基于 Angular 的 UI 组件库，提供丰富的组件和优雅的设计，助您快速构建高质量的 Web 应用。

TypeScript 主题定制

🚀 快速开始

1. 安装组件库

使用 npm 或 yarn 安装组件库到您的项目中

bash 
# 使用 npm
npm install ng-cjf-lib

# 或使用 yarn  
yarn add ng-cjf-lib

2. 导入模块

在您的应用模块中导入所需的组件模块

3. 引入样式
