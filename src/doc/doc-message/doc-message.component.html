💬 Message 全局消息

全局展示操作反馈信息。当需要向用户全局展示提示信息时，例如操作成功、警告或错误信息。顶部居中显示并自动消失，是一种不打断用户操作的轻量级提示方式。

何时使用

  • 操作成功的确认反馈
  • 警告用户注意信息
  • 错误信息的即时提醒
  • 系统状态的实时通知

代码演示

最简单的用法，四种类型的消息提示：信息（info）、成功（success）、警告（warning）和错误（error）。

信息提示 (info) 用于一般的信息提示和说明
成功提示 (success) 用于操作成功的确认反馈
警告提示 (warning) 用于警告用户注意的信息
错误提示 (error) 用于错误信息的即时提醒

可以自定义消息显示的时长，当设置为 0 时，消息将不会自动关闭。通过 removeAll 方法可一次性清除所有消息。

⏱️
时长控制 自定义消息显示时长，默认3秒
📌
永久显示 设置为0时消息不会自动关闭
🧹
批量清除 一键清除所有显示的消息
您好，{{data?.name}}!
消息时间: {{data?.time | date:'yyyy-MM-dd HH:mm:ss'}}

使用自定义模板创建复杂内容的消息。通过模板引用和数据传递，可以实现更加丰富的消息展示。

🎨
自定义模板 支持复杂的HTML内容结构
📊
数据绑定 模板中可访问传入的data对象

手动关闭消息。通过调用 MessageService 的 remove 方法并传入消息 ID，可以在任意时刻关闭指定的消息。

控制机制：每次创建消息时会返回唯一ID，可用于精确控制特定消息的生命周期，提供更灵活的用户交互体验。
