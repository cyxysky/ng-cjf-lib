🔢 NumberInput 数字输入框

通过鼠标或键盘，输入范围内的数值。专为数值输入优化的组件，提供步进控制、精度设置、范围限制等专业功能，适用于财务计算、数据统计等场景。

何时使用

  • 获取标准数值输入
  • 需要精确控制数值范围
  • 财务金额计算场景
  • 设置参数或配置项

代码演示

数字输入框的基本用法，支持三种状态：正常、警告、错误。可通过color属性自定义状态颜色。

正常状态 (normal) 默认状态，适用于常规数值输入
警告状态 (warning) 提醒用户注意输入值的有效性
错误状态 (error) 标识输入值不符合要求

在输入框上添加前缀或后缀，支持属性设置和模板自定义两种方式。

⚙️
属性设置 通过prefix和suffix属性快速添加
🎨
模板自定义 使用ng-container灵活定制样式

通过设置 precision 属性控制小数点位数，确保数值的精确性。

精度控制：precision属性可设置0-20位小数，适用于不同精度要求的业务场景，如财务计算需要2位小数，科学计算可能需要更高精度。

禁用状态下的数字输入框，用户无法进行任何操作。

🚫
完全禁用 禁止所有用户交互，包括键盘输入和按钮点击

只读状态下的数字输入框，用户可以查看但无法修改值。

👁️
仅可查看 用户可以选择和复制内容，但无法修改

通过设置 step 控制每次点击增加或减少按钮时改变的值。

⬆️
递增控制 点击上箭头按钮增加指定步长值
⬇️
递减控制 点击下箭头按钮减少指定步长值
⌨️
键盘支持 使用上下方向键快速调整数值

通过 min 和 max 限制输入范围，确保数值在合理区间内。

Min: 1 Max: 10

通过 formatter 格式化数字，以展示具有具体含义的数据。

💰
货币格式 添加货币符号和千分位分隔符
📊
百分比格式 显示为百分比形式
🔢
自定义格式 根据业务需求自定义显示
