📋 DropMenu 下拉菜单

向下弹出的列表，用于显示链接、动作或菜单。当页面上的操作命令过多时，用此组件可以收纳操作元素。点击或悬停触发子菜单，用于导航、功能切换和展示更多选项。

何时使用

  • 当页面上的操作命令过多时，用此组件可以收纳操作元素
  • 点击或悬停触发子菜单，用于导航、功能切换
  • 展示更多选项，避免界面过于复杂
  • 需要层级结构的菜单导航

👆
悬停触发 (hover)

菜单可以出现在目标元素的不同位置，通过 dropMenuPlacement 设置。

菜单的宽度可以自定义，支持数字（单位为px）或字符串。

下拉菜单支持多级嵌套，鼠标悬停在带有子菜单的项目上会显示子菜单。
