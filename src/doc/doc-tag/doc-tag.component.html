🏷️ Tag 标签

进行标记和分类的小标签。用于标记事物的属性和维度，帮助用户快速识别和分类内容。

何时使用

  • 用于标记事物的属性和维度
  • 进行内容分类和归档
  • 作为过滤器或筛选条件
  • 显示状态或类别信息

自定义颜色

我们提供了多种预设色彩的标签样式，您也可以设置自定义颜色：

预设颜色 primary、pink、red、orange、yellow、green、blue、purple等

设置 tagBorder 属性为 false 可以创建无边框的标签：

有边框 (默认) 标准的边框样式，更加醒目
无边框 更简洁的视觉效果，适合密集布局

设置 disabled 属性可以禁用一个标签：

正常状态 标签可点击，响应用户交互
禁用状态 标签无法被点击、选中或关闭
