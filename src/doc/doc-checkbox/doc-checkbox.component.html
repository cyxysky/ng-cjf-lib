☑️ Checkbox 复选框

灵活的多选择组件，支持单选和批量选择功能。用于在一组可选项中进行多项选择，或表示开启/关闭两种状态。

何时使用

  • 需要从一组数据中选择多个选项时
  • 表示开启/关闭两种状态的切换
  • 在表单中进行多项确认或选择
  • 实现全选/反选等批量操作功能

代码演示

📋 选中值
{{ basicValues | json }}

最基本的复选框用法，展示多个可选项的选择。

通过 checkboxOptions 配置选项，ngModel 获取选中值。
📋 选中值
{{ verticalValues | json }}

通过设置 checkboxDirection="vertical" 使复选框垂直排列。

垂直布局适合选项较多或需要节省水平空间的场景。
🎨 选中值
{{ colorValues | json }}

通过 checkboxColor 自定义复选框的选中颜色。

使用 checkboxIndeterminateColor 自定义半选状态颜色。
🔒 选中值
{{ disabledValues | json }}

可以通过配置选项的 disabled 属性禁用单个选项。

禁用的选项无法被点击和修改，适合权限控制场景。
➖ 选中值
{{ indeterminateValues | json }}

复选框支持半选状态，通过 checkboxIndeterminate 启用。

通常用于表示子选项部分选中的父级节点状态。
✅ 确认状态
用户协议 {{ singleValue ? '已同意' : '未同意' }}

通过设置 checkboxSingle="true" 使用单选模式。

常用于同意条款、确认操作等需要用户明确确认的场景。
