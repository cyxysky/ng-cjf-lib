📝 Input 输入框

基本的表单输入组件，用于接收用户输入的信息。通过鼠标或键盘输入字符，是最基础的表单域的包装。

何时使用

  • 需要用户输入文本内容时
  • 适用于表单数据收集
  • 搜索框、用户名密码等场景
  • 需要限制输入格式或长度时

代码演示

当前值: {{ basicValue }}

最简单的用法，指定输入框的提示文字和默认值。

输入框有三种尺寸：大、默认和小，可以根据不同场景选择合适的尺寸。

S
小尺寸 (small) 适用于紧凑的表单布局和工具栏
M
默认尺寸 标准大小，适用于大部分表单场景
L
大尺寸 (large) 适用于重要表单项和移动端使用

可以添加前缀和后缀，用于在输入框前后添加文本或图标。

📝
前缀支持 文本前缀和图标前缀，以及ng-content支持
📋
后缀支持 文本后缀和图标后缀，以及ng-content支持

可以添加清除按钮，点击清除按钮可以一键清除输入框内容。

输入框可以设置为禁用或只读状态，用于不同的交互场景。

禁用状态 完全不可编辑，通常用于表单验证失败
只读状态 可以选择但不能修改，适合展示场景

输入框可以有不同的状态，用于表示错误或警告信息。

正常状态 默认样式，无特殊状态指示
错误状态 (error) 表示输入有误或验证失败
警告状态 (warning) 提示用户注意或可能的问题

可以限制输入字符的最大数量，并显示字数统计。

🔢
长度限制 设置最大输入字符数
📊
实时统计 显示当前/最大字符数

无边框样式的输入框，适用于特定的设计场景。

应用场景：适用于卡片内部、表格编辑、内联编辑等需要隐藏边框的场景。
