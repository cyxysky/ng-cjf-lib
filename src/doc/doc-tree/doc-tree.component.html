🌳 Tree 树

多层次的结构列表组件，专为展示具有层级关系的数据而设计。支持丰富的交互功能，包括选择、勾选、搜索、异步加载等，让复杂的树形数据展示变得简单高效。

何时使用

  • 展示具有层级关系的数据结构
  • 文件目录或组织架构展示
  • 分类管理或权限配置
  • 需要层级选择的数据场景

获取树状态 展开指定节点 重置展开状态

基础树形组件功能展示：

完整功能 - 支持勾选、选中、展开控制
状态管理 - 提供丰富的状态获取和控制方法
初始化设置 - 支持默认选中、勾选、展开状态

主要方法：

getExpandedKeys getSelectedKeys getCheckedKeys expendNodeByKeys

层级关系可视化：

连接线显示 - 清晰展示父子节点关系
视觉增强 - 适用于复杂层级结构展示
{{ node.title }} {{ origin.type }} {{ origin.description }}

灵活的内容定制：

自定义模板 - 完全控制节点显示内容
数据绑定 - 访问原始数据和节点状态

高性能大数据处理：

虚拟滚动 - 处理大量节点数据
性能优化 - 可配置缓冲区和项目大小

配置参数：

height: 300px itemSize: 24px buffer: 300-600
可以通过treeExpandedIcon模板自定义展开/折叠图标，通过iconTemplate模板自定义节点图标。
设置treeSearchValue属性可对树节点进行搜索，搜索结果会自动展开父节点，并高亮匹配内容。
设置treeAsyncData为true可启用异步加载，通过loadData事件获取子节点数据。使用节点的changeChildren方法更新子节点数据，确保视图自动更新。适用于子节点数据量大或需要从服务器动态加载的场景。
设置treeMultiple属性可切换单选/多选模式。单选模式下只能选中一个节点，多选模式下可同时选中多个节点。
