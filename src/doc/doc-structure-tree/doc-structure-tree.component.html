🌳 StructureTree 组织架构树

用于展示企业组织架构的层级结构，支持用户视图和部门视图两种展示模式。提供清晰的可视化层级关系，适用于人员管理、部门结构展示等场景。

何时使用

  • 展示企业组织架构的层级关系
  • 人员管理和部门结构可视化
  • 支持大量数据的树形结构展示
  • 需要交互式的组织架构浏览

代码演示

组织架构树支持两种视图模式：

用户视图 - 以人员为主的层级展示，显示头像、姓名、职位等信息
部门视图 - 以部门为主的层级展示，突出部门结构和人员数量
交互功能 - 支持节点选择、展开收起、自定义模板等功能
