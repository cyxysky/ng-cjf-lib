📋 Select 选择器

下拉选择器，用于从一组选项中选择单个或多个值。提供丰富的配置选项和灵活的交互方式，适用于各种数据选择场景。

何时使用

  • 从预定义选项列表中选择值
  • 节省空间的下拉菜单
  • 支持单选和多选模式
  • 需要搜索或过滤大量选项
