🔘 Button 按钮

按钮是用户界面中最基本的交互元素，用于触发操作或事件。标记了一个（或封装一组）操作命令，响应用户点击行为，触发相应的业务逻辑。

何时使用

  • 需要用户执行某个操作时
  • 作为表单提交的触发器
  • 导航到其他页面或视图
  • 触发弹窗、抽屉等交互组件

按钮支持多种颜色变体来表达不同的语义和重要级别：

主要颜色 (primary) - 用于主要操作按钮
成功颜色 (success) - 表示成功或确认操作
警告颜色 (warning) - 提示用户谨慎操作
危险颜色 (danger) - 表示可能的危险操作
次要颜色 (tertiary) - 次要操作按钮
幽灵颜色 (ghost) - 无背景透明按钮
默认按钮 虚线按钮
文字按钮 链接按钮

提供四种不同的按钮类型以适应不同的使用场景：

default 标准实心按钮，适用于大多数场景
dashed 虚线边框按钮，常用于次要操作
text 纯文字按钮，适用于不突出的操作
link 链接样式按钮，看起来像超链接
默认形状

支持不同的按钮形状来适应不同的设计需求：

默认形状 标准矩形按钮，适用于大多数场景
圆形按钮 (circle) 适用于图标按钮或特殊交互场景
小按钮 默认尺寸 大按钮

提供三种不同尺寸的按钮来适应不同的使用场景：

S
小按钮 (small) 适用于空间有限的区域或密集的界面布局
M
默认尺寸 标准按钮大小，适用于大多数场景
L
大按钮 (large) 需要强调的操作或在移动设备上使用
正常状态 禁用状态
可用按钮 禁用按钮

按钮可以处于不同的交互状态：

正常状态 按钮可点击，响应用户交互
禁用状态 按钮不可点击，通常表示操作当前不可用
撑满父元素的按钮
撑满父元素的圆形按钮

宽度占满父容器的100%
常用于移动端或需要强调的操作
